== pattern topological-sort
complexity: O(V+E) time · O(V+E) space
nudge: The same release process as deciding whether the courses can be finished. What is the order in which courses come off the ready list?
-- step Count what each course waits for
1 waiting = every course mapped to 0
  hint: What do you track for each course?
  why: How many of its prerequisites are still untaken.
2 unlocks = every course mapped to an empty list
  hint: What do you need when a course is taken?
  why: The courses that depended on it.
3 for course, prereq in prerequisites:
  hint: How do you fill both maps?
  why: One pair at a time.
4     waiting[course] += 1
  hint: What does a prerequisite do to its course?
  why: It is one more thing the course waits for.
5     unlocks[prereq].append(course)
  hint: And to the prerequisite?
  why: Taking it later will release this course.
-- step Take whatever is ready, in order
6 ready = queue of every course with waiting == 0
  hint: Which courses can be taken straight away?
  why: The ones with no prerequisites at all.
7 order = []
  hint: What do you build this time?
  why: The schedule itself, in the order courses are taken.
8 while ready:
  hint: How long do you keep taking courses?
  why: While some course has nothing outstanding.
9     course = take from the front of ready
  hint: Which course next?
  why: Any ready one; the queue takes them in order.
10     order.append(course)
  hint: What does taking it add?
  why: The next course of the schedule.
11     for following in unlocks[course]:
  hint: Who is affected?
  why: Every course that listed this one as a prerequisite.
12         waiting[following] -= 1
  hint: What changes for each of them?
  why: One fewer prerequisite outstanding.
13         if waiting[following] == 0: add it to ready
  hint: When does a course become ready?
  why: When its last prerequisite has been taken.
-- step Return the schedule, or nothing
14 return order if every course is in it, else []
  hint: What if the process stalled?
  why: The courses left form a cycle, so no order exists at all.
== pattern dfs
complexity: O(V+E) time · O(V+E) space
nudge: Record a course only after everything it depends on has been recorded. What does that post-order give you, and which set catches a cycle on the way?
-- step Build the graph
1 needs = every course mapped to an empty list
  hint: Which way do the edges go?
  why: From a course to the courses it needs.
2 for course, prereq in prerequisites:
  hint: How do you fill it?
  why: One pair at a time.
3     needs[course].append(prereq)
  hint: What does each pair add?
  why: An edge from the course to its prerequisite.
-- step Three states and the schedule
4 onPath = empty set
  hint: What catches a cycle?
  why: The courses on the current path; meeting one again is a cycle.
5 done = empty set
  hint: What records courses already scheduled?
  why: The courses fully handled, so they are never walked or added twice.
6 order = []
  hint: What do you build?
  why: The schedule, filled in post-order.
-- step Visit a course
7 if course in onPath: return False
  hint: What if the walk comes back to a course still on its path?
  why: A cycle, so no schedule exists.
8 if course in done: return True
  hint: What if it was already scheduled?
  why: Nothing more to do; reaching it by another branch is fine.
9 onPath.add(course)
  hint: What do you record before going deeper?
  why: That this course is on the current path.
10 for prereq in needs[course]:
  hint: What must be scheduled before this course?
  why: Every one of its prerequisites.
11     if not visit(prereq): return False
  hint: What if a prerequisite hits a cycle?
  why: Pass the failure straight back up.
12 onPath.discard(course)
  hint: What happens when you leave the course?
  why: It is no longer on the path.
13 done.add(course)
  hint: What do you now know about it?
  why: It is fully handled.
14 order.append(course)
  hint: When is a course added to the schedule?
  why: Only now, after all its prerequisites were added. That post-order is a valid schedule by construction.
15 return True
  hint: What does a clean visit return?
  why: That this course could be scheduled.
-- step Visit every course
16 if any visit fails: return []
  hint: Which courses must be visited, and what if one fails?
  why: All of them, since the graph need not be connected. A cycle anywhere means no order.
17 return order
  hint: What is the answer?
  why: The post-order, prerequisites first.
