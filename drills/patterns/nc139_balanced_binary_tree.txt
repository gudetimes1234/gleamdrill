== pattern dfs
complexity: O(n) time · O(h) space
nudge: Measuring heights fresh at every node asks the same subtree the same question over and over. Could the height itself carry the verdict, and once one subtree has failed, what is left to measure?
-- step Read the verdict from the root
1 return measure(root) >= 0
  hint: How do you get a yes or no out of a height?
  why: Any real height means no node broke the rule; -1 is reserved for "unbalanced below".
-- step Measure both children (in measure(node))
2 if node is None: return 0
  hint: What is the height of an empty subtree?
  why: 0, and an empty subtree is trivially balanced, so it never reports -1.
3 left, right = measure(node.left), measure(node.right)
  hint: What must you know about the children first?
  why: Their heights, or -1 if something below them is already unbalanced.
-- step Report trouble or a height
4 if left < 0 or right < 0 or abs(left - right) > 1: return -1
  hint: When does this subtree count as unbalanced?
  why: When a child already failed, or the two heights differ by more than one here. Passing -1 up stops anything above from measuring.
5 return 1 + max(left, right)
  hint: With both sides fine, how tall is this subtree?
  why: One level on top of the taller child, the ordinary height the sentinel rides along with.
